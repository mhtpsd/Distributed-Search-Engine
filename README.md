# Distributed Search Engine

This repository contains a full‑stack, production‑grade distributed search engine.

## Overview
- **Backend** – Java Spring Boot microservices (crawler, parser, indexer, ranking, API).
- **Storage** – PostgreSQL for local development, Bigtable for production.
- **Infrastructure** – GCP Pub/Sub, Compute Engine, Terraform scripts.
- **Frontend** – Next.js UI for search.
- **Docker & CI/CD** – Dockerfiles for each service and Cloud Build pipelines.

## Getting Started
1. Install Java 17+, Maven, Node.js 20+, Docker.
2. Follow the README in each sub‑module for detailed setup.

---

*All code lives under the `Distributed Search Engine/` directory.*
